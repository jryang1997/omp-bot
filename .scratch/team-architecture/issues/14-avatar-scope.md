## Question

## Recommendation

- 要。吉祥物、10 种身体、10 种颜色、表情选择、随运行状态变化的表情、上传图片和裁切。
- 先不要 AI 生成头像。它要单独的图片 API key 和计费，与现在的模型登录不通。
- 直接替换 DS Bot 角色，不让两套并存。已有 bot 按 id 分配一种颜色，身体默认 cursor。
- 待定 Main Bot 的固定形象。
