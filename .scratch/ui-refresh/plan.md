# 界面重构：少字、顺滑、像队友

参照：Emil Kowalski 的 design-eng 技能（动效规则）、Grok Bot 文档写明的原则（Bot 是队友，设置就是发一条消息，技术细节不往前摆）、Linear 的列表和侧边详情、Claude 的对话区。

原则：

- 先说人话：标题写"小总 → 小研"，不写 dlg_xxx；时间写"今天 13:43"，不写 10/16/2026。
- 技术信息收起来：任务号、范围、会话文件、深度这类只在"技术信息"折叠里，默认关。
- 一项一句话：说明文字最多一行，长的收进折叠。
- 动效有目的：抽屉、弹窗、提示进出有过渡；高频的（切换助手、打字、键盘操作）不加。只动 transform 和 opacity，UI 动效不超过 300ms，用强 ease-out 曲线，按下缩到 0.97，不从 scale(0) 出现，退场比进场快，悬停效果只给能悬停的设备，尊重"减少动效"。

步骤（每步截图对比、跑全套测试、单独提交）：

- [x] 1 动效地基：曲线和时长变量；抽屉滑入、弹窗缩放淡入、提示进出、菜单从按钮处展开；悬停只给鼠标；减少动效时只留淡入淡出
- [x] 2 详情抽屉：任务详情和派活详情改成"一句话标题 + 一行时间 + 内容 + 紧凑操作"，技术信息折叠
- [x] 3 任务页：卡片改紧凑行，统计并成一行，"详情"文字链接改成整行可点
- [x] 4 设置抽屉：说明文字瘦身，长说明收进折叠
- [ ] 5 对话区：中文日期、头部权限标签归位、新消息进场
- [ ] 6 暗色和手机检查
