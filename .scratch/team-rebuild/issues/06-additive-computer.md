# 06: 绑定电脑只加能力

**What to build:** 绑定电脑的 bot 保留本机 omp 原生工具、扩展、技能和 MCP，客机工具加在上面。客机工具在两种可执行档里都不弹审批，描述写明在 Linux 共享电脑里。电脑档的工具面校验和披露文案换成两套工具都在的说明。

**Blocked by:** None - can start immediately

**Status:** ready-for-agent

- [ ] 绑定电脑的 bot 启动参数里没有 `--no-tools`、`--no-extensions`、`--no-skills`
- [ ] overlay 不再因为绑定电脑关项目 MCP 或用户 MCP
- [ ] overlay 把所有客机工具设为 allow
- [ ] chat 档的收窄和工具面校验不变
- [ ] 客机工具描述以"在 Linux 共享电脑里"开头
- [ ] 能力面板和运行时文案不再说电脑模式没有本机工具
