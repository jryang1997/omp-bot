# Triage 标签

五个标准 triage 角色使用同名标签。

| 标准角色 | 本仓库标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 维护者需要评估工单 |
| `needs-info` | `needs-info` | 等待提出者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 规格完整，可交给代理实施 |
| `ready-for-human` | `ready-for-human` | 需要人工实施 |
| `wontfix` | `wontfix` | 不实施 |

当技能要求应用某个 triage 角色时，使用表中对应的标签。在本地 Markdown 工单顶部附近，将标签写入 `Status:` 行。

以后要改名，编辑本仓库标签列，并同步修改已有工单的对应状态。
